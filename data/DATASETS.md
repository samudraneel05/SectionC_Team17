# Datasets

The volumes used in this study are all publicly available. Raw data is
not redistributed in this repository due to size; use the links below.
Result summaries are in `data/*.json`.

| Dataset | Used for | Source |
|---|---|---|
| Bentheim sandstone micro-CT (1 MPa, 5.854 µm) | Grayscale porous-media denoising (main result) | Zenodo: <https://doi.org/10.5281/zenodo.5548582> — file `1MPa 1_5854um.zip` (~1.2 GB, 1007 TIFF slices). We take a 192³ central crop normalized to [0,1] by percentile. |
| BrainWeb T1 phantom (181×217×181, 1 mm) | MRI denoising control | <https://brainweb.bic.mni.mcgill.ca/> — anatomical model `t1_icbm_normal_1mm_pn0_rf0`. Cite Collins et al. 1998. |
| 11 sandstones (Berea, segmented) | Binary porous-media control | Digital Rocks Portal: <https://doi.org/10.17612/F4H1-W124> — segmented Berea volume + a synthetic sphere pack generated locally (`foj3d/exp_rock.py`). |
| engine / foot / jaw / pepper / teapot (256³ synthetic CT volumes) | CT ablation reproduction | R²-Gaussian project data, mirrored on the 3D FoJ authors' Google Drive: <https://drive.google.com/drive/folders/1YZ3w87XrCNyjDRos6gkY8zgT5hESl-PN> (the *engine* volume is the one used in all reproduction runs). |

## Ground-truth files expected by the scripts

- `data/engine/vol_gt.npy` — engine 256³ (from the Drive folder above; `vol_gt_64.npy`, `vol_gt_128.npy` are downsamples).
- `bentheim.zip` — downloaded automatically by `foj3d/exp_rock2.py` if absent (~1.2 GB).
- BrainWeb `.mnc`/raw slice — fetched inside `foj3d/exp_mri.py` from the BrainWeb site.
- Binary volumes — generated by `foj3d/exp_rock.py` (sphere pack) and sliced from the Berea scan.
